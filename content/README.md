# 04\_Base\_de\_Conocimiento - Guia de uso

## Que es

`04_Base_de_Conocimiento/` es la wiki viva reusable de Terapia Liberal. Aca deberian vivir nodos estables, no recortes sueltos ni borradores de trabajo.

## Regla operativa

- priorizar mejorar notas existentes antes que multiplicar nodos;
- crear nota nueva cuando el objeto deje valor reusable fuera de un caso puntual;
- distinguir entre `nodo vivo`, `alias` e `import` para no mezclar entidad con recorte;
- si un archivo es solo staging, curaduria o marcador, conviene moverlo fuera de esta carpeta.

## Estructura minima sugerida

Toda nota viva deberia responder rapido:

- que es
- por que importa en TL
- que cambio
- con que conecta
