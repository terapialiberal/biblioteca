# Cártel Phoebus

Cartel formado en 1924 por fabricantes de lámparas (Osram, Philips, GE) para limitar la vida útil de las bombitas de luz a 1000 horas. Inventaron la obsolescencia programada como modelo de negocio. TL: la obsolescencia no es una falla de diseño — es una decisión deliberada de un cartel que nunca fue punido. Lo mismo aplica a smartphones, electrodomésticos y software.
