# BIOS - Sistema de Arranque

El BIOS como metáfora TL: el código que se ejecuta antes del sistema operativo visible. Las decisiones que se toman en el arranque determinan todo lo que viene después sin que el usuario las vea. Aplicado a política: las reglas electorales, los tratados fundacionales y las arquitecturas institucionales son el BIOS del sistema político.
