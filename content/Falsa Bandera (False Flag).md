# Falsa Bandera (False Flag)

Operacion donde un actor ejecuta, permite o manipula un hecho para atribuirlo a otro y obtener legitimidad politica, militar o policial.

En TL se usa con cautela: no como comodin explicativo, sino como categoria historica de atribucion manipulada, casus belli, infiltracion y gestion de percepcion publica.
