# Falsa Bandera (False Flag)

Operación donde un actor ejecuta, permite o manipula un hecho para atribuirlo a otro y obtener legitimidad política, militar o policial.

En TL se usa con cautela: no como comodin explicativo, sino como categoria histórica de atribución manipulada, casus belli, infiltración y gestion de percepción publica.
