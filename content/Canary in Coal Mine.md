# Resumen General
Un "canario en la mina de carbón" es un indicador temprano de peligro. En análisis geopolítico, ciertos eventos o reacciones funcionan como advertencias de tendencias mayores.

# Canarios Contemporáneos

## 1. Financieros
- **Repos overnight**: Bancos no confían entre sí → crisis
- **Gold premium**: Oro premium sobre papel → fuga a seguridad
- **Insider selling**: Ejecutivos venden → saben algo

## 2. Políticos
- **Desplatformeos selectivos**: Quien es censurado indica líneas rojas
- **Lawfare coordinado**: Múltiples jurisdicciones al mismo tiempo
- **Suicidios de testigos**: "Arkancide" pattern

## 3. Sociales
- **Militarización de policía local**: Preparación para desorden
- **Ejercicios de "contingencia"**: Lo que practican es lo que esperan
- **Movimientos de élites**: Bunkers, pasaportes, ciudadanías

# Cómo Usarlo
1. Identificar el "canario" para cada área
2. Monitorear su estado
3. Cuando el canario muere, actuar
