# Virality Project

> [!INFO] Entidad de Control (Tier B)
> **Resumen:** Consorcio académico (liderado por Stanford Internet Observatory) que funcionó como "lavadero de censura" para el gobierno de EEUU durante la pandemia.
> **Función Real:** Permitir que el DHS censurara disidencia sanitaria eludiendo la Primera Enmienda.

## Qué Fue

El Virality Project unió a universidades (Stanford, Washington, NYU) y empresas de monitoreo (Graphika) para rastrear "narrativas antivacunas" en tiempo real y reportarlas a las plataformas de redes sociales (Twitter, Facebook, Google) para su eliminación.

## Objetivo: "Malinformación Verdadera"

Su aspecto más distópico fue la categoría de **"historias verdaderas de efectos secundarios de vacunas"**.
Admitieron explícitamente que **información 100% verídica** debía ser censurada si "promovía la vacilación ante las vacunas". La verdad se subordinó a la política pública.

## El Mecanismo (Censura Por Proxy)

El Gobierno (DHS/CISA) no puede censurar legalmente.

1. El DHS habla con el Virality Project (ONG/Academia).
2. El Virality Project marca los tweets de ciudadanos.
3. Las plataformas borran el contenido citando "consejo de expertos".
   _Resultado:_ Censura estatal disfrazada de moderación privada.
