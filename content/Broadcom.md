# Broadcom

Gigante de semiconductores y software de infraestructura. Adquirió VMware por \$69B (2023). Proveedor clave de chips para data centers, redes y IA. TL: la guerra de chips no es solo TSMC — Broadcom controla la capa de conectividad que hace posible el cloud computing global.
