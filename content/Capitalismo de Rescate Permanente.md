# Capitalismo de Rescate Permanente

Sistema donde las pérdidas son privadas hasta que se vuelven sistémicas, momento en que se socializan vía backstops de bancos centrales. 2008, 2020, 2023 (SVB). TL: el riesgo moral no es un bug del sistema — es el feature que permite a las élites financieras tomar apuestas asimétricas con la certeza de que el Estado cubre las pérdidas.
