# Atanor (Presión Social)

> [!ABSTRACT] Hipótesis Informativa
> El **Atanor** es el horno alquímico que mantiene el fuego constante. Forensemente, es la **Gestión de la Presión Social**. El Tier A utiliza este horno (los medios, la economía, la polarización) para mantener al Tier C en un estado de "cocción" perpetua, forzando la transmutación de las leyes y costumbres mediante el calor del conflicto.

## Análisis Forense

- El secreto del Atanor es no dejar que el fuego se apague. El Tier B gestiona el combustible (noticias, crisis) para asegurar que la masa social esté siempre bajo la presión necesaria para aceptar el siguiente cambio sistémico.
