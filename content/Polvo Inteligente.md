# Polvo Inteligente (Smart Dust)

## Resumen Ejecutivo
**¿Qué es?** Sensores microelectromecánicos (MEMS) del tamaño de un grano de arena o polvo, que pueden set esparcidos en el aire, objetos o cuerpos, y comunicarse inalámbricamente.
Desarrollado originalmente por **DARPA** y la Universidad de Berkeley.

**¿Por qué importa?** Es la **Vigilancia Ubicua Total**.
Imagina millones de "cámaras/micrófonos" invisibles flotando en el aire de una ciudad enemiga, o dentro de un edificio.
No necesitas instalar cámaras; simplemente "rocías" el ambiente.
Si se inhala o ingiere, podría actuar como un rastreador interno o interfaz neural básica (red neuronal artificial física).
Se conecta con la red 5G/6G para transmitir datos en tiempo enjambre.

## Análisis (Tiers)

### Tier A (La Materia Que Ve)
- **Panóptico Físico:** El objetivo final es que el entorno físico mismo sea inteligente y vigilante. "Las paredes tienen oídos" deja de set metáfora.

### Tier B (Operativa)
- **Uso Agrícola:** Se vende como tecnología para monitorear cultivos (humedad, plagas) grano a grano, pero la tecnología es dual (militar).

### Tier C (Narrativa)
- "Monitoreo ambiental avanzado"
