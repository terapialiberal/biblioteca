# Proyecto Agorá (BIS)

> **Perfil TL:** El proyecto del BIS para crear la infraestructura global de las CBDCs. El fin del dinero libre.

## Resumen Ejecutivo
**¿Qué es?** Iniciativa del [[Banco de Pagos Internacionales\|BIS (Banco de Pagos Internacionales)]] lanzada en 2024 para desarrollar un "Unified Ledger" (Libro Mayor Unificado) que permita la interoperabilidad entre las monedas digitales de bancos centrales (CBDCs) de diferentes países.

**¿Por qué importa?** Es la infraestructura técnica para el control monetario global. Permitiría programar el dinero: decidir en qué puedes gastar, cuándo caduca tu dinero, y cortarte el acceso si no cumples ciertas condiciones.

## Análisis De Poder (Tiers)

### Tier A+ (Las Reglas)
El BIS coordina a 7 bancos centrales (Fed, BCE, BoE, BoJ, Banque de France, Bank of Korea, Banco de México) + el sector privado ([[Mastercard]], [[Visa]], [[00_Glosario - Conceptos Fase 1#SWIFT\|SWIFT]]).

### Tier B (Operadores)
Los bancos comerciales ([[JPMorgan]], [[HSBC]], [[Citi]]) participan como "partners" para asegurar adopción.
