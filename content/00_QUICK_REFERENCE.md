## 🔁 FLUJO DE TRABAJO TÍPICO

1. **CAPTURA**: Importá el artículo (vía Monica o Clipper).
2. **ENTIDADES**: `/scan` para ver si faltan nodos en tu bóveda.
3. **ANÁLISIS**: `/forense` para deconstruir la narrativa y ver activos reales.
4. **PRODUCCIÓN**: `/producir` para elegir formato (A, B, C o D).
5. **POST**: `/archivar` para generar la nota de archivo premium.
